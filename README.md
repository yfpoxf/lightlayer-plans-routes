## 三档线路：同样的钱，带宽差 5 倍

Premium 优化线路走 CN2、CMIN2，面向中国大陆，回国延迟最低；Standard 标准线路介于中间；Global 国际线路带宽给得最大、单价最低，代价是国内访问要绕路。

同价年付最能说明问题。洛杉矶三个 $24.99 的组合，优化线路只给 20Mbps，标准给 50Mbps，国际给到 100Mbps。如果你人在国内，主要用途是 SSH 管机器、进网站后台、传小文件，20Mbps 的优化线路体验明显好过 100Mbps 的国际线路，因为后者国内延迟普遍在 200–300ms，晚高峰还会丢包。反过来，跑海外业务、做下载站、面向非中国大陆用户，国际线路那 100Mbps 才是实打实的。

按这个逻辑套到别的机房：香港和新加坡的优化款给 10Mbps，台北和马尼拉只给 5Mbps。香港、台北这类近岸机房延迟本来就低（公开数据在 30–50ms 区间），带宽小一点对建站影响不大；马尼拉 5Mbps 就要掂量一下，同一个 $24.99 还有 10Mbps 的国际款可选。

## 第三方实测：圣何塞、洛杉矶、马尼拉各是什么水平

**圣何塞（2026 年 10 月，SJ-VP04-L，1vCPU / 1GB / 50GB / 1Gbps，Debian 12）**

这是目前能拿到的最新一份数据，测的是优化线路。硬件是单核 Platinum 9242，GB5 单核 820，整机 HQ 总分 20797，负载很低；硬盘 46GB，随机读写一般、顺序读写尚可，内存支持气球回收。回程延迟上，电信大多 128–177ms 且稳定，移动普遍 126–181ms，联通延迟偏高、部分地区表现较差，晚高峰可能抖动。回程路由是电信走 CN2、移动走 CMIN2、联通走 9929 + 4837。单线程上下行带宽多在 100Mbps 以上，国际节点带宽充足。

**洛杉矶（2024 年中，2 核 2GB / 50GB，母机 EPYC 7H12）**

两次测评的数据可以互相印证：UnixBench 2358.9，宝塔跑分 13846，磁盘读写约 220MB/s；本地电信 300M 环境下 ping 160–170ms，波动小、无丢包，ping.pe 的国内节点零丢包；30M 带宽基本跑满，晚高峰 21:30 本地下载 3.6MB/s；另一台 30M / 4GB 的机器实测 I/O 约 225MB/s，启用了 BBR。网络结构是去程三网直连西海岸自家节点后接 Cogent 进机房，回程电信、联通、移动全部强制走移动 CMIN2（AS58807）回国。流媒体方面，实测可解锁奈飞美国区，TikTok 和部分北美平台也能开。

这两组数据来自 2024 年，硬件平台和现在在售的批次未必相同，只能当作洛杉矶整体线路走向的参考，不要拿它当当前性能承诺。

**马尼拉（优化线路，E5-2699v4）**

磁盘 I/O 约 197MB/s。去程电信走 CN2，联通和移动经香港直连菲律宾；回程电信走 CTG/CN2 经香港回内地，联通走 AS10099 对接 AS4837，移动直连香港转 CMI。属于东南亚节点里网络做得比较规整的一个。

## 会真的影响使用的几个限制

**开通后所有端口默认是封的。** 这不是故障，需要在面板防火墙里手动添加要放行的端口，否则 SSH 之外一概不通。第一次买的人经常卡在这里。

**不支持 IPv6。** 官方产品线目前只有 IPv4，需要 IPv6 的项目直接排除。

**机房之间的 IP 属性不一样。** 香港机房的 IP 不是原生 IP，解锁 Netflix、Disney+ 这类流媒体会受限；圣何塞的机型则自带原生 IPv4。要原生 IP 就往日本或美国机房选。

**没有明确的退款政策，也没有明确的 SLA 承诺。** 这两条在官网找不到硬承诺，遇到问题只能开工单协商。对稳定性有硬性要求的企业业务，这一点要提前想清楚。

**工单是英文的，响应一般几个小时，没有 7×24 在线客服。** 简单问题能解决，复杂的沟通成本会比国内商家高。

**升级规则不统一。** 不限流量的套餐只能升带宽，限流量的套餐只能升流量、不能升带宽；弹性云可以随时升配置，降级要联系客服；而 $24.99 这档特价年付一般不支持升降级，买之前把配置定好。

**支付方式需要结账页确认。** 较新的资料写支持支付宝、PayPal、信用卡，2024 年的测评则说当时只有 PayPal。两边口径不一致，下单前在结账页看一眼最稳。

## 谁该买，谁别买
